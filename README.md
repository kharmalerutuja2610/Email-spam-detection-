Email Spam Detection 📧

Project Overview

This is a Machine Learning project that detects whether an email message is Spam or Ham (Not Spam).

Technologies Used

- Python
- Pandas
- Scikit-learn
- Machine Learning

How It Works

1. The user enters an email message.
2. The text is converted into numerical features.
3. The Machine Learning model analyzes the message.
4. The model predicts whether the message is Spam or Ham.

Example

- Input: Congratulations! You won a free prize.
- Output: Spam

Project Objective

The objective of this project is to understand how Machine Learning can be used to classify email messages.
